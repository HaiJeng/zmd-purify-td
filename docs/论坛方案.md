首先，本文的主要思想

用「基建净化地图＋碎片化剧情＋角色 BOSS 化」，把抽卡、基建和主线从割裂的三套系统，整成一条完整的体验链。

我希望玩家不再是“通完马桶就把基建丢在一边”，而是通过基建一步步修复环境、解锁故事，最后直面、并在卡池里抽到自己亲手打过的 BOSS。

我为什么想写这篇

         作为一个开服就玩、大号长草，于是周末又开了个小号速通的老吃家，我最大的感受就是：这游戏想做的东西很多，但总玩下来是割裂的。

我用小号重新回顾了整个开荒过程，基建和抽卡几乎是完全独立于主线之外的。

何意味？

1. 基建，在爆炸物解锁的时候，造一个爆炸物流水线挂一晚上就可以拆了，接着扔个零件流水线就没有戏份了，直到解锁蓝铁，这个时候拉一下电量，把蓝铁装备元件弄出来，主 C 穿一套（手残可以四个人都穿）就可以一直撑到四谷地剧情结束。

2. 抽卡，大家或许是认为终末地是“抽卡二游”嘛，所以就该抽卡，然后用卡池角色组一队通马桶。

但是，莱万汀这个卡池完全也是割裂的，不是吗？主线里有莱万汀什么事情吗？正常来说，第一个卡池不应该是矿脉的小红帽，或者是研究院的伊冯？

难道说，终末地要玩家吃完主线那一大坨后，再去品鉴不知道写得如何的莱万汀支线？（虽然对我这个牢粥玩家来讲，写得还不错）

我在品鉴了两遍终末地后，总结下来就两点：

1. 剧情写得很烂，废话多，谜语人，燃又燃不起来，催泪也催泪不来，塔塔炸得我是一脸无语。是的，塔塔很可爱很有趣，但是终末地将这些全都放在了可选里，而不是围绕着塔塔来展开剧情。整个剧情的玩下来，就是我在通马桶，最后不是马桶炸了而是塔塔炸了，真的是可爱到爆炸。

2. 基建说实话，成就感非常薄弱，插满了桩子和滑索后，四谷地还是那个吊样子，哦，炸弹清理侵蚀路障也算改造环境吧？倒是武陵有点意思，拿液态息壤可以将陆地上的侵蚀清理干净，并且可以改变水体类型。但是也就那样，终末地在不在都无所谓。

3. 小文案写得不错，点名表扬：“嵌合正义”，“我不用死了——管理员恩情文”。（众所周知，四大天王总是有第五个）

鉴于上述种种，我有了一个相对激进的改造思路：把抽卡、剧情、基建重新焊成一套，用来扬长避短。

一、 基建部分：基建改成推进剧情、改造环境、突破封锁的核心工具。下面先用四号谷地和武陵两个区域，举一下具体会怎么改。

  - 以四号谷地的谷地通道为例，我们需要用炸弹炸柱子来解除裂地者的雾，一炸就没了，说实话，这 low爆 了，玩的是真尬啊，都有宇宙飞船了还扔土制炸弹呢。

      - 欸，🙋‍♀️我有一个点子：

      - 众所周知，玩基建类游戏，最重要的一点就是攀科技树，那么为什么不这么搞？

      - 我们将前面那群难民的剧情直接对半砍，那个源石抑制剂完全莫名其妙，为什么要写？就为了后面打完罗丹，在电梯旁边摆个没多少玩家会注意的尸体，凸显一下世道艰辛？

      - 直接设定碾骨氏族的红雾具有长时型、侵染性，只是破坏了它们产出红雾的装置，也不能将环境恢复，而长期接触红雾会使环境异常、生物异变并性情狂躁。要不然罗丹转阶段猛吸红雾何意味？

      - 在拍出分基地后，我们拍一个研究所出来，需要拍出环境检测器，研究出支持干员可以在雾中战斗的装备。

      - 干死罗丹后，就要解析罗丹的掉落物，作为攀裂地者科技树的重要素材，甚至可以作为碾骨者金装的科技树前置。

      - 而难民营地的等级，直接与环境修复挂钩。随着玩家发展谷地通道的科技树，比如研发出驱红雾的电桩、吸收土地中红雾的大型装置，将这些提交到难民营地，营地难民会自动铺设到预定的位置，同时更新地图的地貌，可以保留红雾侵染导致变异狂化的生物，作为该地图的特色。

 - 再比如武陵：

      - 直接设定为武陵以清波寨为前哨站，寨民是耗材。

      - 如果检测到侵蚀，糖糖阮一如果来武陵求救，就说明侵蚀严重了（原剧情里就有写汤汤来找管理员帮忙的，不如往黑暗里写，而不是现在这种奇怪的设定，什么叫寨民会打劫路人，会去偷武陵的粮食，武陵的巡卫抓到人了还要好吃好喝的供着？凭什么？）。

      - 如果检测到侵蚀，但是清波寨没有来求助，那就是正常情况，按照预案处理就好。

      - 只要保证不要的垃圾会自觉去清波寨聚集，只需要提供一点微不足道的食物，就可以不用管他们的死活，无本万利。

    - 管理员收到武陵求助，从四号谷地前往武陵，结果落地是清波寨，反而武陵已经沦陷。

    - 整个武陵都沉没于侵蚀大海中，玩家需要靠基建慢慢铺设施、做大范围净化，别整那幽默小水枪了，能滋一大片我是真没绷住。

    - 直接拍个分基地下来，然后类似前面的四谷地，拍个研究所，一步一步解析，从寸步难行到干员可以行动，再然后大范围的清理。

    - 比如海上直接铺路、水坝、抽水机（原版这抽水机是真的搞）

    - 收拢零星的难民和他们与侵蚀拼搏、一代一代积累的经验和科技，拼接到从四号谷地发展或者终末地自有的科技树上。

    - 基建设施铺开之后，地图地形、可通行路线、人类聚集点都会跟着变化，直接成为推动玩家继续玩的动力。

二、 剧情这块：干脆别搞那种“一个版本一条主线 + 在剧情里硬塞当期卡池角色”的老路了，改成偏《黑暗之魂》《艾尔登法环》那种“碎片化叙事”。

  - 大部分故事丢在地图各处：遗留的记录、人类聚集点、奇怪的建筑、NPC 只说半句实话那种。

  - 这样一来，3D 剧情演出那边文案压力没那么夸张，也不需要每个版本都拍一长段大电影。

  - 结合前面的基建，直接给玩家用侵蚀、红雾圈起来，像2077那样给你上个永远过不完的6个月，或者永远是90%只会减的区域侵蚀进度条，亦或者是一堆嗷嗷待哺的难民，再由卡池角色，比如前面的汤汤作为区域领路人，带你到安全区，带你找矿，带你搜救难民搜寻科技树。甚至作为队伍的第5人打输出，跑路的时候聊天逗闷子（目前终末地是做了的，虽然只有几句话）

  - 主线就是净化整个地图，故事以小文案为主玩家自己拼凑就是了，反正不要离开管理员恩情文就完事了。

  - 庄方怡的小师妹情也能这么写，没有守护住武陵对武陵百姓的愧疚，没有守护住管理员成就的愧疚，对管理员愿意来救自己的感动。（啊，是你，鸣潮的守岸人、卡提西亚）

三、 卡池角色：除了前面的汤汤可以作为区域领路人外，还可以将大版本的主C设计为地图的关底大BOSS。

  - 就比如前面的武陵，原剧情是啥？刚进武陵的时候有一段庄方怡实力展示，“天雷滚滚，你想往哪里逃！”.jpg。然后是“管理员不来研究不会成功”的息壤剧情，再然后是和管理员甜蜜 ml。

  - 哥们真觉得武陵不是危在旦夕啊，而是水深火热。

  - 直接给她拍个最终 BOSS 的设定，毕竟研发息壤和“天雷滚滚”的时候都说“她是在硬撑”，那不如直接给她侵蚀了得了，被侵蚀的同时也以己身牵制侵蚀，玉龙形态是她的半身，攻击形式就是水雷（水是侵蚀，取自水花子，雷是她自身的能力），作为地图最终 BOSS。

  - 场景直接设定在核心区，在她被侵蚀前，其他天师 + 一代一代与侵蚀斗争积攒的科技为底为其制作抑制装置，使其处于半疯状态，才会有清波寨的保留、零星的天师带领的人民尝试收复失地（这么写是因为我很讨厌英雄主义，而且如果不写其他天师的作为，那不是很蠢吗，那武陵一代又一代人的拼搏又算是什么）。

  - 侵蚀的原因甚至可以直接设定为因为往裂隙里灌了息壤（终末地里有这段，不过是需要收集的线索）

  - 初始版本卡池就是汤汤，山里人，熟悉景玉谷各种小路大路，作为区域领路人，只要引路剧情写得不是一坨，这不抽？

  - 玩家要结合前面拍的基建，做出环境净化的机器，干员行动、净化庄天师半身的装置。

  - 打死她，然后用装置净化她，然后在下一个小版本推出净化后该角色的卡池，大方向设计不变，数值和机制进行削弱/加强。Boss形态都那么厉害了，再来点恩情小作文，再把服饰搞一下，作为大版本的主C，这不抽？

  - 甚至可以设计卡池角色对区域研究/净化有特殊加成，可以了解更多的故事，但是不能搞出没有这个角色这个地图没法玩，要做到：

    - 抽，可以减少地图开荒的时间，但是需要投入时间培养这个角色

    - 不抽？不抽你就慢慢开荒呗

    - 保证两种玩法在总时间上是相当的。

四、一些补充

1. 地图怪物怎么设计？

我考虑的是按照套娃的形式，越外层越危险

前面也有写，罗丹的掉落物可以作为科技树核心，那么小怪的掉落物作为加速研究就好了

当然，可别来个需要xx的yy一定个数才能解锁某个科技，那不是二游该有的，那是mmo或者单机才能玩的

2. 我最i的塔防怎么办？

（真的i吗）

可以以侵蚀/红雾净化的进度为标准，打了有奖励，不打不影响

掉落物可以加速研究

干员可以入驻防御塔，作为特殊防御塔存在，不同干员有不同的效果

只要保证塔防时，卡池角色作为特殊选项而非唯一解，那就不算逼氪

3. 我最i的滑索怎么办？

那当然是，按照净化进度解锁，作为每个进度的支线，做出来后交给寨民/难民，他们会在已净化的区域按预设铺设，也可以自己拉电线铺设

甚至当净化100%后，直接解锁低空翼装飞行都可以，反正只能在净化完的地图飞。

诶哟，终末地文案怎么这么坏啊，写的都是啥啊。

1. 林奈那个剧情，我会这么改：

    嘲讽学婊：管理员的论文是几乎所有研究员拜读过的，有个研究员占小便宜，装可怜让失忆的管理员帮她买材料做实验，最后的研究成果算她的，在佩里卡的提醒下管理员明白为什么感觉奇怪，并且佩丽卡表示已经处理了对方

    几日后，可以在终端收到一封来自“终末地科研伦理委员会”的格式化通告，提及该研究员因学术不端被调离关键岗位。不展示惩罚过程，只展示结果。

    为了不让玩家觉得自己是个傻X，在佩丽卡提醒前，在送完荞花后，又被索要柑实开始都会有一个隐晦的“直觉选择”（如“总觉得哪里不对”/“举手之劳而已”），选前者能让佩丽卡更早介入。这能增强玩家（管理员）的代入感。

2. 武陵开启种田任务以及那个天师和耕牛的任务，耕牛那个很明显在致意袁老先生，但是写的是又臭又长，谜语人就罢了，什么叫接水要我去庄方怡家门口接？

直接把这俩合并还不如写成：

    管理员与野怪搏斗波及了旁边的田地，一位老先生突然出现保护了土地并清理了小怪，表示要注意着点，并给管理员传授如何种田，此任务开启游戏功能：种田功能。

管理员种下后，老爷子突然消失了，之后玩家可以在该田地周围找到实验田所有人的流转信息，比如这么写：“…原持有人XX于[数据删除]年离世。根据《[数据删除]法案》第X条，无人继承之试验田自动收归公共农业数据库。感谢其对文明延续之贡献。”

    甚至可以再加一段，玩家收获时有低概率产出+15%，也不用写明为什么，本就是要碎片化+谜语人，懂得都懂。

3. 为何不简单扩写下嵌合正义的文案？

嵌合正义-其一：

    野兽和敌人突然暴动，科考团被袭击，存活的人慌不择路跑入一个山洞，战斗人员和部分学者为了保护实验数据，将一部分年轻人和数据封存进了山洞中，他们在外面死战不退

    管理员闻讯前来支援路上进行小规模战斗，到达山洞时已经尸横遍野，尸体堆上是一把长枪贯穿了两个人形成了三角

    枪上有一个光点，类似于游戏开局超长的新手任务里，小墓碑的调查点，管理员可以交互，交互时可以选择将长枪拔出，获得物品【染血变形的“嵌合正义”】

    大概如下：

        选项A（拔出长枪）：镜头直接第一人称并给到手部特写，握住枪杆时有明显的阻力感和音效，拔出瞬间，枪上的二人会倒下，假设一个是干员，一个是裂地者，管理员会保住干员并慢慢将其放倒。并获得物品 【染尘的“嵌合正义”】。
