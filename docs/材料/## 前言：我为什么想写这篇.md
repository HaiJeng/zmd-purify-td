### 我为什么想写这篇

作为一个开服就玩、大号长草，于是周末又开了个小号速通的老吃家，我最大的感受就是：**这游戏想做的东西很多，但总玩下来是割裂的**。

我用小号重新回顾了整个开荒过程，基建几乎是完全独立于主线之外的。

何意味？

基建，在爆炸物解锁的时候，造一个爆炸物流水线挂一晚上就可以拆了，接着扔个零件流水线就没有戏份了，直到解锁蓝铁，这个时候拉一下电量，把蓝铁装备元件弄出来，主 C 穿一套（手残可以四个人都穿）就可以一直撑到四谷地剧情结束。

然后是抽卡，大家或许是认为终末地是“抽卡二游”嘛，所以就该抽卡，然后用卡池角色组一队通马桶。

但是，莱万汀这个卡池完全也是割裂的，不是吗？主线里有莱万汀什么事情吗？正常来说，第一个卡池不应该是矿脉的小红帽，或者是研究院的伊冯？

难道说，终末地要玩家吃完主线那一大坨后，再去品鉴不知道写得如何的莱万汀支线？（虽然对我这个牢粥玩家来讲，写得还不错）

我在品鉴了两遍终末地后，总结下来就两点：

1. 剧情写得很烂，废话多，谜语人，燃又燃不起来，催泪也催泪不来，塔塔炸得我是一脸无语。是的，塔塔很可爱很有趣，但是终末地将这些全都放在了可选里，而不是围绕着塔塔来展开剧情。整个剧情的玩下来，就是我在通马桶，而不是凸显塔塔的可爱。
2. 基建说实话，成就感非常薄弱，插满了桩子和滑索后，四谷地还是那个吊样子，哦，炸弹清理侵蚀路障也算改造环境吧。倒是武陵有点意思，拿液态息壤可以将陆地上的侵蚀清理干净，并且可以改变水体类型。
3. 小文案写得不错，点名表扬：“嵌合正义”，“我不用死了——管理员恩情文”。

### 鉴于上述，我有了一个激进的脑洞，如何扬长避短，以及如何将抽卡、剧情、基建融合起来：剧情碎片化 + 角色 BOSS 化 + 基建净化地图

 **基建部分**：既然剧情碎片化、角色 BOSS 化，那基建也可以顺势改成“**净化整张地图**”的核心工具。
  - 这次以四谷地的谷地通道为例，我们需要用炸弹炸柱子来解除裂地者的雾，说实话，这太 low 了，玩的是真尬啊。
    - 我给一个思路：
      - 众所周知，玩基建类游戏，最重要的一点就是攀科技树，那么为什么不这么搞？
      - 我们将前面那群难民的剧情直接对半砍，莫名其妙的剧情为什么要写？
      - 直接设定碾骨氏族的红雾具有长时型、侵染性，如果只是破坏了它们产出红雾的装置，并不能将环境恢复。
      - 在拍出分基地后，我们拍一个研究所出来，需要拍出环境检测器，研究出支持干员可以在雾中战斗的装备。
      - 干死罗丹后，就要解析罗丹的掉落物，作为攀裂地者科技树的重要素材，甚至可以作为碾骨者金装的科技树。
      - 那么难民营地的等级，直接与环境修复挂钩。随着玩家发展谷地通道的科技树，比如研发出驱红雾的电桩、吸收土地中红雾的大型装置，将这些提交到难民营地，营地难民会自动铺设到预定的位置，同时更新地图的地貌，可以保留红雾侵染导致变异狂化的生物，作为该地图的特色。
 - 再比如武陵：
    - 直接设定为武陵以清波寨为前哨站，寨民是耗材。
      - 如果检测到侵蚀，糖糖阮一如果来武陵求救，就说明侵蚀严重了（原剧情里就有写汤汤来找管理员帮忙的，不如往黑暗里写，而不是现在这种奇怪的设定）。
      - 如果检测到侵蚀，但是清波寨没有来求助，那就是正常情况，使用预案处理就好。
      - 只要保证不要的垃圾会自觉去清波寨聚集，只需要提供一点微不足道的食物，就可以不用管他们的死活，无本万利。
    - 管理员收到武陵求助，从四谷地前往武陵，结果落地是清波寨，反而武陵已经沦陷。
    - 整个武陵都沉没于侵蚀大海中，你需要靠基建慢慢铺设施、做大范围净化，别整那幽默小水枪了，能滋一大片我是真没绷住。
    - 直接拍个分基地下来，然后类似前面的四谷地，拍个研究所，一步一步解析，从寸步难行到干员可以行动，再然后大范围的清理。
    - 收拢零星的难民和他们与侵蚀拼搏、一代一代积累的经验和科技，拼到已有的科技树上。
    - 基建设施铺开之后，地图地形、可通行路线、人类聚集点都会跟着变化，直接成为推动玩家继续玩的动力。
- **卡池角色**：为了弥补碎片化叙事带来的“角色出场感不强、流水不好看”，我一开始想的是——**当期卡池角色直接做成版本关底 BOSS**。
  - 就比如前面的武陵，原剧情是啥？刚进武陵的时候有一段庄方怡装逼的剧情，“天雷滚滚，你想往哪里逃！”.jpg。然后是“管理员不来研究不会成功”的息壤剧情，再然后是和管理员甜蜜 ml。
  - 哥们真觉得武陵不是危在旦夕啊，而是水深火热。
  - 直接给她拍个最终 BOSS 的设定，毕竟研发息壤和“天雷滚滚”的时候都说“她是在硬撑”，那不如直接给她侵蚀了得了，被侵蚀的同时也以己身牵制侵蚀，玉龙形态是她的半身，攻击形式就是水雷（水是侵蚀，取自水花子，雷是她自身的能力），作为地图最终 BOSS。
  - 场景直接设定在核心区，在她被侵蚀前，其他天师 + 一代一代与侵蚀斗争积攒的科技将为其制作抑制装置，使其处于半疯状态，才会有清波寨的保留、零星的天师带领的人民尝试收复失地（这么写是因为我很讨厌英雄主义，而且如果不写其他天师的作为，那不是很蠢吗）。
  - 这个版本卡池就是汤汤，山里人，熟悉景玉谷各种小路大路，作为区域领路人，只要引路剧情写得不是一坨，这不抽？
  - 玩家要结合前面拍的基建，做出环境净化的机器，干员行动、净化庄天师半身的装置。
  - 打死她，然后用装置净化她，然后在下一个小版本推出净化后该角色的卡池，大方向设计不变，数值和机制进行削弱/加强。
- **剧情这块**：干脆别搞那种“一个版本一条主线 + 在剧情里硬塞当期卡池角色”的老路了，改成偏《黑暗之魂》《艾尔登法环》那种**碎片化叙事**。
  - 大部分故事丢在地图各处：遗留的记录、人类聚集点、奇怪的建筑、NPC 只说半句实话那种。
  - 这样一来，3D 剧情演出那边文案压力没那么夸张，也不需要每个版本都拍一长段大电影。
  - 结合前面的卡池和基建，直接给玩家用侵蚀、红雾圈起来，像2077那样给你上个永远过不完的6个月，或者永远是90%只会减的区域侵蚀进度条，亦或者是一堆嗷嗷待哺的难民，再由卡池角色，比如前面的汤汤作为区域领路人，带你到安全区，带你找矿，带你搜救难民搜寻科技树。甚至作为队伍的第5人打输出，跑路的时候聊天逗闷子（目前终末地是做了的，虽然只有几句话）
  - 主线就是净化整个地图，故事以小文案为主玩家自己拼凑就是了，反正不要离开管理员恩情文就完事了。
  - 庄方怡的小师妹情也能这么写，没有守护住武陵对武陵百姓的愧疚，没有守护住管理员成就的愧疚，对管理员愿意来救自己的感动。（啊，是你，鸣潮的守岸人、卡提西亚）

#### 我最i的滑索怎么办？

那当然是，按照净化进度解锁，作为每个进度的支线，做出来后交给寨民/难民，他们会在已净化的区域按预设铺设，也可以自己拉电线铺设

甚至当净化100%后，直接解锁低空翼装飞行都可以，反正只能在净化完的地图飞。

#### 关于 UP 角色的详细定位

我设定里 UP 角色是**"区域净化专家"**，而不是"没他就打不过"。

| 维度 | 有 UP 角色 | 没 UP 角色 |
| :--- | :--- | :--- |
| **剧情** | 解锁专属个人剧情，看到更深层的故事 | 通过环境、文档拼凑主线，也能看懂大致剧情 |
| **塔防** | 派驻防御塔，质变效果（如治疗溅射+净化） | 用通用模块或 2-3 个常驻干员组合实现类似功能 |
| **资源获取** | 效率高，有专属任务快速刷材料 | 升级科技、做成就、参与活动也能稳定获取，就是慢一点 |

**核心原则：UP 是捷径，不是门票。**  
- 抽到了，体验更好、效率更高、剧情更完整；  
- 没抽到，也能玩完所有内容，只是要多花点时间、多动点脑子。
